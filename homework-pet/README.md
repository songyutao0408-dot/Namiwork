# 作业伙伴

小学生作业打卡 × 电子宠物养成。给四年级孩子用的，把"写作业"变成"照顾一只需要她的小家伙"。

> ⚠️ 这个目录和本仓库的纳米Work展示页项目**无关**，是一个独立的小应用，只是暂时放在这里。

---

## 怎么用

**不需要安装任何东西。** 用浏览器打开 `index.html` 就能跑，数据存在本机浏览器里，不联网、不上传。

### 三种用法

| 方式 | 做法 | 适合 |
|------|------|------|
| **直接打开** | 双击 `index.html` | 先试试看 |
| **本地起个服务** | `python3 -m http.server 8080` 然后访问 `http://localhost:8080` | 想装到手机主屏（PWA 需要 http） |
| **发布到网上** | 把这个目录传到 GitHub Pages / Vercel / Cloudflare Pages | 手机随时打开，推荐 |

发布后在手机浏览器里打开 →「添加到主屏幕」，图标和体验就跟原生 App 一样，离线也能用。

---

## 家长怎么操作

点右上角 ⚙️，默认密码 **1234**（进去后可以改）。里面四个页签：

- **录作业** —— 手动加 / 一键复制昨天 / 从模板点选
- **日常项** —— 设置每天自动出现的固定作业（比如"每天阅读 20 分钟"），设一次就不用再管
- **同步** —— 生成链接发给孩子；也能导出/恢复数据备份
- **设置** —— 惩罚强度、假期模式、饥饿速度、现实奖励兑换表

### 两台设备怎么同步

没有后端，靠"同步码"：

```
你手机：录好今天的作业 → 家长 → 同步 → 复制链接
       ↓ 微信发给孩子
孩子设备：点开链接 → 自动导入今天的作业
```

链接里就带着作业内容（base64 编码），不经过任何服务器。孩子端也可以手动粘贴。

**记得定期在「同步 → 导出备份」存一份 JSON。** 清浏览器数据会把记录清掉。

## 核心机制

### 喂食

完成一项作业 = 喂宠物一次。喂多少**按当天完成率算**，不是固定值：

```
单项喂食量 = 40 ÷ 当天作业总数
```

这样作业多的一天不会更容易养宠物。当天全部完成额外 +15。

### 饥饿

- 默认每小时掉 1.5 点（满值 100），约 3 天见底
- 周末速度减半（可关）
- **单次结算最多按 3 天算** —— 出远门十天回来，宠物最惨也就是"饿到底"，不会已经没救了
- 用时间戳差值计算，关掉 App 也在饿
- 一天的分界在**凌晨 4 点**，晚上 11 点做完作业不会算到第二天

### 饿到底之后（家长可选三档）

| 档位 | 行为 | 恢复方式 |
|------|------|---------|
| **温和**（默认） | 生病，变灰打蔫，停止成长，**不会死** | 完成作业即恢复 |
| **标准** | 挂 2 天后离家出走，等级成就全保留 | 连续 2 天全部完成，它自己回来 |
| **硬核** | 挂 3 天后死亡，需重新领养 | 旧宠物进入「纪念相册」 |

> 建议从温和模式开始。永久死亡对这个年龄的孩子容易变成"反正已经死了"的放弃心态，激励系统会直接失效。

### 请假卡

每月 2 张，**孩子自己决定什么时候用**。用掉当天不掉饱食度，而且会把当天已经扣的补回来（晚上才想起来请假也有效）。家长可以在设置里补发。

### 进化

```
蛋 → 幼体(10 项) → 成长期(40 项 + 连击 7) → 成熟期(120 项 + 连击 21)
```

成熟期按**各科完成占比**分支：数学→智慧型、语文/阅读→文艺型、英语→旅行型、科学→探索型。

四条分支**每条都占到 15% 以上**才会进化成稀有的**全能型**。想拿到它就得主动补自己不爱做的那一科。

### 积分

每完成 1 项 +2 分，当天全部完成再 +10 分。按每天 5 项估算，一周约 100 分。可以换宠物装扮，也可以换家长自定义的现实奖励（在设置里改兑换表）。

## 文件结构

```
homework-pet/
├── index.html            整个应用（HTML + CSS + JS 都在里面，无构建步骤）
├── manifest.webmanifest  PWA 配置
├── sw.js                 离线缓存
├── icon.svg              图标
└── README.md
```

单文件是刻意的：没有 npm、没有构建、双击就能开，改起来也不用管工具链。

---

## 数据

全部存在浏览器的 `localStorage`（键名 `hwpet.v1`），不发送到任何地方。

清除浏览器数据 / 换设备 / 换浏览器都会丢，所以：**定期导出备份**。
